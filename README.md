# HealthMap
This project aims to develop a user-friendly web mapping application using Python and Django Framework to help users locate nearby healthcare amenities.

## Running the Application

Follow the steps below to set up and run the application:

1. Clone the repository
   ```bash
   git clone https://github.com/clemokey/HealthMap.git
   cd HealthMap
   ```

2. Create the Conda environment  
   Open the project directory in the Anaconda Prompt and run:
   ```bash
   conda env create -f environment.yml
   ```

3. Activate the environment
   ```bash
   conda activate HealthMap
   ```

4. Run the application
   ```bash
   python manage.py runserver
   ```

   If everything is set up correctly, the application will be live and accessible in your browser at http://127.0.0.1:8000/.
